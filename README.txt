ARTORA — Art & Commission Marketplace
=======================================

Cara menjalankan:
1. Extract folder artora-commerce.
2. Buka folder tersebut di VS Code.
3. Klik dua kali index.html, atau gunakan extension Live Server.
4. Halaman yang tersedia:
   - index.html   = landing page
   - login.html   = halaman login
   - register.html = register client/artist

Catatan:
Ini adalah FRONT-END DEMO. Login/register belum memakai database/backend.
Semua tombol dan validasi dasar dibuat dengan JavaScript.
Untuk versi berikutnya bisa ditambahkan PHP + MySQL, Supabase, dashboard artist,
upload portfolio, detail commission, checkout, chat, dan database pengguna.
